### 简介

```
HOT TREND V1.0 —— 一个个人自用的短视频热点观察台。

▍做了什么
把抖音、快手的公开热点信息，整理成 9 个中文栏目：今日热门视频、热门音频、
热门特效、爆款文案、经典语录、抖音热门榜、快手热门榜、上升最快榜、历史收藏。
支持搜索、平台与分类筛选、一键复制文案、本地收藏导出。

▍技术要点
· React 18 + TypeScript(strict) + Vite 5 + Tailwind CSS 3
· 纯静态：数据放在 public/data/*.json，无后端、无数据库、无账号体系
· hash 路由，规避 GitHub Pages 刷新 404
· GitHub Actions：每天北京时间 08:00 自动更新 + Pages 自动部署
· 更新失败自动保留上一次有效数据，绝不写入空值
· 手机与电脑自适应，明暗双主题

▍一点说明（重要）
本项目不调用任何付费数据接口，也不绕过平台登录、验证码或签名校验。
抖音和快手都没有面向个人开发者的免鉴权公开接口，所以数据来源是
「人工核验的快照 → 脚本校验清洗 → 静态 JSON 入库」。
平台未公开的播放量、点赞量、热度、排名，页面一律显示「未公开」，
不做任何估算和推测 —— 这是我自己定的底线。

源码：github.com/Lebekan/HOT-TREND
在线体验：lebekan.github.io/HOT-TREND

#前端开发 #React #TypeScript #GitHubPage #独立开发
```

## 二、发布前必读

| 项目 | 说明 |
|---|---|
| 视频规格 | H.264 High / yuv420p / 1920×1080 / 30fps，B 站直接可投 |
| 音轨 | **无音轨**。B 站允许静音稿，但建议在站内「创作中心 → 音频」挑免费配乐后合成 |
| 封面 | 已提取片头帧，也可自行上传更醒目的封面（B 站要求 ≥1146×717） |
| 自制声明 | 选「自制」 |
| 转载 | 不需要 |

### 配乐建议（避免版权风险）

优先用 B 站创作中心自带的**免费音乐库**，或选择 CC0 / 公共领域曲目。
不要使用抖音、快手热门 BGM 原曲 —— 那些多为商业版权音乐，投稿易被判侵权，
且与「不伪造、不侵权」的项目定位不符。

### 可能遇到的审核提醒

1. **提到「抖音」「快手」**：属于客观描述，不是搬运内容。只要视频里没有出现
   平台水印、没有播放他人视频片段，通常不会有问题。本片只展示自己写的界面截图。
2. **示例数据标注**：视频里界面顶部有「示例骨架数据」的黄色提示条，
   这是真实状态，无需隐藏。反而是加分项。
3. **若被判「含推广」**：简介里已说明是个人项目、无商业推广，可申诉说明。
